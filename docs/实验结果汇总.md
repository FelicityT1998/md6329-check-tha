## 0. 文献中的模型设计与本研究的对照（衔接方案 §7.9.2）

本节回答四个问题：过往研究为什么选那种模型；各自用了哪些输入、做了哪些特征工程；针对不同数据类型的架构怎么设计；评估口径和表现与我们相差多少、差在哪里、为什么。文献信息取自 `litreview/abstracts.md` 里存的摘要；标「全文」的细节是摘要里没有写、凭全文记忆补充的，写报告前需要再核对一次原文。

### 0.1 先统一口径：不同指标之间不能直接比较

- **AUROC 与 AUPRC 不能互换。**3.4 节表里的 0.79、0.85 都是 AUROC；我们报的 0.37–0.39 是 AUPRC。按 AUROC 比，我们的临床模型是 0.807，临床+影像是 0.820，**与这些文献在同一量级，并不差**。
- **AUPRC 受事件率支配。**随机模型的 AUPRC 等于事件率。所以跨研究比较时用「**提升倍数 = AUPRC ÷ 事件率**」。本研究事件率 5.5%，AUPRC 0.386，即 7.0 倍；Jang 2023 事件率 2.4%，AUPRC 0.28，即 11.7 倍。
- **终点决定难度。**影像学进展（KL 升级）的结局本身就是从片子上读出来的，影像天然占优（Tiulpin 2019：仅影像 0.79）。置换终点还取决于症状、就医行为和手术意愿，所以临床变量的作用上升（Gillani 2026：手术终点「部分反映就医可及性等非疾病因素」）。
- **内部验证和外部验证不能放在一起比。**外部验证普遍掉分：膝 OA 中位 0.81 → 0.75（Gillani 2026）；World COACH 0.81 → 留一队列 0.64。我们的主估计是内部嵌套 CV，伪外部的留一中心见 §4。

### 0.5 结论：差距在哪里，怎么补

1. **临床部分不差，反而比同终点的文献强**：AUROC 0.81 对 Jang 的 0.68。这来自 CHECK 的髋部专项查体和症状问卷，不需要「追赶」。
2. **影像部分是真正的短板**：只用影像时，AUROC 比 Jang 和 Tiulpin 低 0.08–0.10。原因有三层：
   - **缺监督**：文献的影像特征都用疾病标签训练过，包括 KL、OARSI、随访分级，或者直接测量几何量；我们的是冻结的通用特征。
   - **池化抹掉了空间细节**：OA 的关键征象（关节间隙变窄、骨赘、股骨头变平）都是局部、细小的几何结构，全局平均池化会把它们和周围骨盆、软组织混在一起。
   - **样本量**：1,963 个髋，文献是 9,000–25,000，不够端到端微调整个 CNN。
3. **对应的改进**（§2.6，10-23 跑）：保留 14×14 空间特征图；可训练残差头加注意力池化；用 11 个基线 OARSI 读片项作辅助监督目标；把像素读出的 OARSI 预测值当作 Jang 式「测量量」交给 elastic net。读片分只当训练标签用，预测时只用像素，从而避开 R 组的直接泄漏。

2. **冻结的 ImageNet 像素特征只有弱信号，而且骨干的选择很关键。**ResNet-18 纯影像 AUPRC 0.093，只比患病率 0.055 高一点；DenseNet-121（Tiulpin、von Schacky 用的骨干）有 0.122 / AUROC 0.687，显著更好。在人口学之上，DenseNet 影像带来**显著增量**：D+I 对 D 的 ΔAUPRC 为 +0.072 (0.020, 0.137)，ΔAUROC 为 +0.103。但在全部临床特征之上，增量缩小到 +0.020 (−0.049, 0.076)，不显著，说明影像里的信息大多已经被查体和症状覆盖了。数值上最好的无泄漏模型是 M0 + DenseNet（0.386 / 0.820）。ResNet-18 线性融合的 Δ 只有 +0.007。把影像作为 token 放进 FT-Transformer 反而**显著变差**（−0.12），影像维度带来的过拟合大于它的信号。FiLM 只调制 [CLS]，不参与注意力，伤害小一些（比 token 好 0.077，CI 不跨 0），但仍不如不加影像的 M2。多尺度特征（layer3+4）对纯影像只多 +0.015 (0.000, 0.033)。**SimCLR 继续预训练也没有带来提升**（+0.007，CI 跨 0）。训练过程：CPU 上 25 epoch，用时 52 分钟，第 20 epoch 最好；线性探针 log-loss 从 0.2249 降到 0.2130，与 ImageNet 特征的 CKA 为 0.59，防遗忘措施生效、表征没有塌缩。但 1,968 张无标签裁剪图的对比学习学到的主要是采集风格，学不到 OA 形态。
3. **读片评分（KL / OARSI）能把 AUPRC 从 0.37 提到 0.58**，但这是放射科医生读出的结论，而且很可能是成对读片的口径（B4），不能和「像素」等同看待。像素和读片之间的差距，本身就是一个结果：从像素里提取 OA 形态，需要监督微调或者分级标签，冻结的通用特征拿不到这部分信息。
4. 离散时间头（2/5/10 年风险）**没有训练到位**：10 年累计风险均值 0.34（实际约 0.05），AUROC 0.50–0.54。原因是早停看的是二分类头，而年 hazard 从 0.5 起步，偏置还没降下来训练就停了。时间头在现有结果里只起辅助正则的作用（λ=1 时二分类最好）。修正办法是把偏置初始化成基线 hazard 的 logit（−5.3，`FTT_DT_BIAS`），M2 和 M4 已重跑，结果用 `_dtinit` 标签保存：
   - **M2_dtinit**：10 年风险头 AUROC 0.699、AUPRC 0.252（修正前 0.537 / 0.110），校准截距 0.47、斜率 1.73，仍偏低估、偏保守；二分类头 AUPRC 0.270（修正前 0.336）。在 repeat 0 上配对比较，Δ 为 −0.011 (−0.059, 0.043)，不显著；repeat 之间的波动很大。
   - **M4_dtinit**：二分类 0.230，10 年风险头 AUROC 0.665，影像 token 同样拖后腿，对 M2_dtinit 的 Δ 为 −0.146 (−0.245, −0.052)。
   - 结论：时间头修好以后能给出可用的 2/5/10 年风险，但区分度仍低于专门的二分类模型。报告里的主指标用二分类头，时间头作为补充输出。

### 2.6 影像分支优化（10-23）：影像能识别什么，怎么补

**问题**：读片评分（KL / OARSI）能把 AUPRC 从 0.37 提到 0.58，冻结的影像特征却几乎没有增量。

**病理出发点**：OA 在髋关节正位片上的征象依次是：
- 关节软骨变薄 → 关节间隙变窄。上外侧最常见，表现为股骨头向上外侧移位；
- 关节面不再光滑，出现骨赘（髋臼和股骨，分上、下缘）；
- 软骨下骨硬化、囊变；
- 晚期股骨头变平、出现支撑反应（buttressing）。

另外，髋臼形态（发育不良、外侧覆盖不足）和 cam 畸形是结构性的危险因素。这些征象都是**局部的、毫米级的几何结构**。

**1）冻结的全局嵌入能识别什么？**（`08_imghead.py probe` → `imghead/probe_items_frozen.csv`）

方法：用 PCA-64 + 岭回归，从嵌入预测每个读片项，5 折按受试者分组，报告 Spearman ρ。

| 读片项 | ResNet-18 | DenseNet-121 | SimCLR | **残差头 + 辅助监督**（测试折） |
|---|---|---|---|---|
| KL | 0.24 | 0.31 | 0.31 | **0.45** |
| 上方间隙狭窄 | 0.23 | 0.23 | 0.23 | **0.34** |
| 内侧间隙狭窄 | 0.22 | 0.27 | 0.24 | **0.36** |
| 髋臼上缘骨赘 | 0.17 | 0.24 | 0.17 | **0.28** |
| 髋臼下缘骨赘 | 0.22 | 0.23 | 0.26 | 0.29 |
| 股骨上缘骨赘 | 0.19 | 0.24 | 0.28 | **0.40** |
| 股骨下缘骨赘 | 0.15 | 0.15 | 0.24 | **0.33** |
| 硬化 | 0.08 | 0.11 | 0.10 | 0.14 |
| 囊变 | 0.02 | 0.03 | 0.05 | 0.01 |
| 股骨头变平 | 0.07 | 0.05 | 0.02 | 0.01 |
| 支撑反应 | 0.16 | 0.17 | 0.20 | 0.24 |

解读：
- 冻结特征只能弱弱地「感觉」到间隙变窄和骨赘（ρ 约 0.2–0.3），硬化、囊变、股骨头变平基本识别不出来。
- 原因是全局平均池化把毫米级的局部征象和周围的骨盆、软组织平均到了一起；而且 ImageNet 特征从没见过「关节间隙」这个概念。
- 残差头保留了空间信息，又有读片监督，间隙狭窄和骨赘的 ρ 提高了 0.1–0.2。
- 囊变和股骨头变平仍然学不到：这两项阳性率很低，而且 256² 的裁剪分辨率不够。这是下一步改进的方向（见 4）。

**2）可训练的影像头**（`08_imghead.py train`；**只跑了 repeat 0 的 5 个外折**，和其他模型在 repeat 0 上配对比较）

结构：冻结 DenseNet-121 到第 3 个 dense block（1024×14×14 特征图）→ 1×1 卷积降到 64 通道 + BN + ReLU → 2 个残差块（3×3 卷积 – BN – ReLU – 3×3 卷积 – BN + 恒等跳连）→ 注意力池化与全局平均池化拼接 → 输出头。训练 30 epoch，固定轮数、不早停；预热 3 epoch + 余弦衰减；空间抖动 ±1 格；Dropout2d 0.1。

|---|---|---|---|---|
| 冻结 DenseNet + PCA-32 + elastic net（原 M3） | 0.122 (0.098–0.222) | 0.687 | 0.87 | — |
| + AdaBN（BN 统计在我们的裁剪上重估） | 0.086 | 0.633 | 0.87 | 变差 |
| 线性头：GAP + BN + 多任务（无残差、无空间） | 0.250 (0.176–0.370) | 0.780 | 0.95 | 对原 M3 +0.094 (0.020, 0.193) |
| 残差头，无辅助任务 | 0.504 (0.398–0.609) | **0.896** | 0.31（未校准） | — |
| **残差头 + 11 个 OARSI 辅助任务** | **0.518** (0.403–0.624) | 0.877 | **0.88** | 对原 M3 **+0.362 (0.254, 0.464)**；对线性头 +0.268 (0.154, 0.362)；对无辅助 +0.014 (−0.042, 0.077) |

- **增益主要来自空间结构加残差卷积**：线性头 → 残差头，AUPRC +0.27。辅助监督对区分度的帮助不显著，但改善了校准（斜率 0.31 → 0.88），而且让中间特征变得可解释（上表 ρ 提高）。

### 2.7 FT-Transformer：BatchNorm 对比与训练超参数修正（10-23）

**诊断**：在旧设置下，lr 为 1e-3 的配置最佳 epoch 是 12–27，第 32–47 epoch 就早停了；lr 为 3e-4 的配置要到 100 epoch 左右才收敛。学习率固定、没有预热，耐心值只有 20，验证集每折约 25 个事件、噪声大，于是在欠拟合阶段就被停掉了。

**修正**（`lib_ftt.py`，全部是环境变量开关，默认值等于旧行为）：
- `FTT_SCHED=warmcos`：前 10 epoch 线性预热，之后余弦衰减；最佳检查点只从第 10 epoch 起选；
- `FTT_MIN_EPOCHS=40`：40 epoch 之前不允许早停；
- `FTT_PATIENCE=30`；
- 早停准则沿用总损失（`FTT_ES=total`），时间头偏置初始化为 −5.3；
- `FTT_NORM=bn`：Transformer 块里的 LayerNorm 换成按 token 的 BatchNorm，统计量在 batch × token 上汇总，readout 的归一化改为 BatchNorm1d。

**结果**（单种子，同一套折号和架构；`*_epochs.csv` 记录了每个模型的最佳 epoch 和停止 epoch）：

| 版本 | 二分类 AUPRC（repeat 间 SD） | AUROC | 校准斜率 | 10 年风险头 AUPRC / AUROC / 斜率 | 2 年 / 5 年 AUROC | 停止 epoch（最小 / 中位） | 最佳 epoch 中位 |
|---|---|---|---|---|---|---|---|
| 旧：总损失早停 | 0.323 (0.022) | 0.771 | 1.15 | 0.249 / 0.751 / 2.65 | 0.89 / 0.83 | — | — |
| **v2 LayerNorm** | **0.337** (0.037) | **0.780** | 1.15 | 0.257 / 0.749 / 3.02 | 0.89 / 0.83 | 44 / 66 | 36 |
| **v2 BatchNorm** | 0.329 (**0.013**) | 0.769 | 1.14 | **0.267** / 0.753 / **1.90** | **0.90 / 0.85** | 42 / 55 | 25 |

配对差值（repeat 0）：
- v2 LN 对旧版：ΔAUPRC +0.025 (−0.032, 0.086)；
- v2 BN 对 v2 LN：−0.031 (−0.103, 0.042)；
- 对 M0：v2 LN 为 −0.014 (−0.078, 0.057)，v2 BN 为 −0.046 (−0.096, 0.009)。

结论：
1. **「欠拟合阶段早停」的问题已经消除**：75 个模型里没有一个在第 40 epoch 之前停下；停止 epoch 的中位数从约 45 推后到 55–66。新训练策略对旧版有小幅提升，但不显著。
2. **BN 对 LN**：二分类区分度没有显著差别。BN 的 repeat 间方差最小（SD 0.013，是所有版本里最稳的），离散时间头的校准明显更好（斜率 1.90 对 3.02），5 年 AUROC 也更高。原因：BN 的批统计提供了额外的噪声正则；表格 token 之间的尺度差异很大，BN 按通道在整个批上标准化，对 LayerNorm 的逐样本标准化是一种补充。不过 Transformer 文献的默认选择仍然是 LN（Gorishniy 2021），因为 BN 依赖批大小，推理时要用滑动统计，所以两者都要报告。
3. **影像端的 BN**：可训练残差头里的 BN 是必需的（见 §2.6）；冻结骨干上的 AdaBN 反而变差（Δ −0.076 (−0.130, −0.027)）。
4. **最终 M2**：BN 版的 3 种子集成 `m2ens_DESCLB_v2_bn_s3` 正在跑（独立进程，约 20:40 完成）。如果它超过当前主版本 `_lam1_dtinit_es_s3`（0.343），就替换掉；否则维持现状，把 BN 作为消融报告。

### 2.9 时序泄漏审计（10-23 晚，`95_temporal_audit.py` → `results/temporal_*.csv/json`）

**起因**：影像头的结果太好（只用影像 AUROC 0.88），用户指出 §2.6 的两项检查证明力不够。标签置换只能排除管线泄漏；同 KL 分层用的是带未来信息的 KL。所以从研究问题出发重新审计：先定预测时点 t₀，再按时间线逐项判断每个输入能不能纳入（方案 §0.1），然后看信号沿「距置换的时间」怎么分布。

**1）每个输入在 t₀ 时是否已经确定**（方案 §0.1 的准入表）
- 像素：DICOM 的拍摄年份是 2003–2006（54 / 211 / 221 / 1 张），和入组期一致；TIFF 是基线文件夹里的胶片扫描件，没有日期。各折之间没有受试者重叠。**像素里没有 t₀ 之后的信息。**
- 表格主集 DESCLB：全部来自 t₀ 的问卷、查体和样本。研究性标志物是事后批量检测的，但测的是 t₀ 的样本，时间上可以纳入，只是临床上拿不到。
- **R 读片：不可纳入。**`Rontgen_opT10` 是随访结束后成对、按已知顺序读的（Macri 2022；编码 9 =「失访缺片」）。Macri 2022 还报告，这种读法得到的髋 ROA 患病率是单独读基线片的 2.9 倍。
- 结局：只用随访数据定义。但排除 299 个 10 年状态未知的髋，相当于以「随访到 10 年」为条件。影像分数**预测不了**删失（AUROC 0.52），所以这一步不会制造出影像信号。

**2）信号沿「距置换的时间」怎么分布**（AUROC：各时间窗的事件对全部无事件髋；临床模型是 5 个 repeat 的均值，影像相关的模型目前只有 repeat 0）

|---|---|---|---|---|---|---|
| M0 D+E+S | 0.821 | 0.901 | 0.845 | 0.705 | 0.803 / 0.300 | 0.795 / 0.243 |
| M0 DESCLB（临床） | 0.807 | 0.903 | 0.826 | 0.683 | 0.785 / 0.271 | 0.775 / 0.222 |
| M2 FT-Transformer | 0.787 | 0.896 | 0.820 | 0.628 | 0.762 / 0.253 | 0.751 / 0.202 |
| 影像头（残差 + 辅助） | 0.877 | 0.977 | 0.917 | 0.713 | 0.859 / 0.420 | 0.844 / 0.358 |
| 影像头（残差，无辅助） | 0.896 | 0.983 | 0.902 | **0.804** | 0.882 / 0.421 | 0.867 / 0.343 |

滞后 2 年时的配对 Δ（repeat 0，按受试者自助 1,000 次）：
- M0 + 像素对 M0：ΔAUPRC **+0.204 (0.117, 0.278)**，ΔAUROC +0.083 (0.047, 0.123)；
- 只用影像对 M0：+0.137 (0.024, 0.238)；
- 无辅助对有辅助：+0.001 (−0.073, 0.068)。

**3）结论**
1. **没有发现输入层面的时序泄漏。**像素和表格主集都在 t₀ 时确定。唯一带未来信息的是 R 读片，它不进任何主模型。
2. **「太好」的主要来源是疾病分期，不是泄漏。**所有模态，包括纯临床，对 1–3 年内置换的髋都接近完美（0.90–0.99），越往后越弱（0.63–0.80）。1–3 年内置换的 23 个髋里，基线 KL 2–3 的有 17 个，5 个在过去一年看过骨科（无事件髋只有 4%）。也就是说，这部分髋在 t₀ 时已经站在手术门口。影像对它们最敏感，因为关节间隙变窄就画在片子上。
3. **去掉这部分以后，像素的增益仍然存在**：滞后 2 年，M0 + 像素 0.883 / 0.484，对纯临床 ΔAUPRC +0.204，CI 不跨 0。8–10 年这个时间窗，无辅助的影像头是所有模型里最高的（0.80）。
4. **辅助监督不是信号来源**：读片目标确实带有未来信息，但完全不用读片的残差头区分度一样（全部 0.896，滞后 2 年 0.882），所以影像头的区分度不是从读片「学到未来」得来的。辅助任务只改善了校准和可解释性（§2.6）。
5. **需要改的说法**：
   - 「M0 + 像素 ≈ M0 + 读片」只能说成「与一个带未来信息的读片参照相当」，不能说成「复现了放射科医生的增益」；
   - 「同 KL 分层」不能当作排除泄漏的证据；
   - 报告的主表要同时给全部事件和滞后 2 年两套数字。
6. **顺带查出的数据问题**：受试者 211091 和 2068693 的基线骨盆片是同一张（裁剪嵌入的余弦相似度 0.999 / 0.998；尺寸都是 4182×5095，两人的年龄、BMI、KL 都不同），其中 211091 的右髋是事件髋。属于影像与受试者的错配，影响 1 个事件髋；在报告的 Data 一节披露。
7. **还没能排除的乐观偏差**：残差头的设计（层数、30 epoch、注意力池化）是看过 repeat 0 外折结果以后定下来的。repeat 1–4 用的是同一批受试者，只能检验划分带来的方差，检验不了这种「设计选择」带来的乐观。这一点写进 Limitations。

**5 个 repeat 的补跑**（`logs/run_imghead_rep14.ps1`，10-23 23:37 启动，约 02:40 结束）：repeat 1–4 的主影像头和融合，以及 repeat 0–4 的无辅助对照和它的融合（`m5noaux_pix_logit_DESCLB`）；最后用 `08_imghead.py export` 合并到 `oof/`，repeat 0 的原文件备份在 `oof/rep0_backup/`。完成后重跑 90 / 91 / 94 / 95，并更新本节和 §2.6 的数字。

## 2.10 补救实验：FTT 的 [I] token 改喂交叉拟合像素 logit（2026-10-24 晚，`15_m2pix.py`）

- 设定：和 `m2ens_DESCLB_lam1_dtinit_es`（单种子，FTT_DT_BIAS=-5.3，FTT_ES=total）同折、同架构、同种子；token 入口的 LayerNorm 换成 Identity（LayerNorm 对 1 维输入恒输出常数，会把 logit 抹掉）。训练/验证髋用内折交叉拟合 logit，外折测试髋用全外训练集头的 logit，与 M0 融合口径一致。33 分钟。

- 配对 Δ（repeat 0，按人 bootstrap 1,000 次）：对同配方 M2（0.323）+0.147（0.038, 0.250）；对 M4 冻结 token（0.230）+0.275（0.161, 0.379）；**对 M0 + 像素 logit（0.552）−0.095（−0.150, −0.043）**。
